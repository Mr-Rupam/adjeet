# Audit of the rejected direction

Scope: current source, existing local preview at port 3002, supplied logo, phone screenshot and content/integration inventory. This is a design audit, not a security, legal or factual certification.

Evidence: audit/existing-home-mobile.png and audit/existing-home-full.png. Those show the prior implementation, captured before production edits in this pass. This pass only writes PRODUCT.md and this isolated design pack.

| Finding | Why it fails | Decision |
|---|---|---|
| Header substitutes a compact block-letter AD JEET and arrow symbol | Discards the supplied identity's serif lettering, monogram and yellow sweep | Original PNG in every branded placement |
| Cobalt Anton hero dominates the first screen | Palette and typography are imposed on the brand | Cyan/yellow palette derived from the logo; supporting Barlow/Hind typography |
| Hero uses a boxed fictional dimensional wordmark under the copy | The artwork competes with the identity and does not serve as the requested background | One full-bleed architectural plate with exact original logo layered over it |
| Day/night is a separate lighting demonstration | Misreads the core interaction the user requested | Global theme changes the hero background itself |
| Huge all-caps promise, sticker year and secondary CTAs compete | Adds noise before visitors see what the company makes | One short title, concise offer and single enquiry action |
| Chat launcher overlaps the visible hero artwork on the phone capture | Fragments the mobile action hierarchy | Coordinated enquiry dock after the first action leaves view |
| The new homepage styling diverges from older service/contact templates | A homepage-only patch leaves multiple visual systems | Apply one system across all existing page templates |
| Five photographs support only a subset of ten service categories | A uniform large image catalogue would require fabricated proof | Large real work imagery where available; labelled material studies elsewhere |
| Contact copy contains two-hour/same-day promises | A visual refresh is not verification of service commitments | Avoid amplifying them in proposed copy; preserve source for owner review |
| Gallery metadata and visible image text have conflicts | Specific location/year captions can become misleading | Suppress disputed details in designs and flag source reconciliation |
| Coverage array mixes cities, districts and regions | Its length is not proof of an administrative district count | Speak about coverage places and North Bengal |
| Font support and form name validation differ | Bengali-capable typography is not Bengali-capable submission | Keep that distinction explicit |

## Keep and build upon

The existing app has useful route structure, ten service definitions, real enquiry destinations, a validated form, analytics wrappers and publication gates. These are integration assets. The redesign should preserve them while replacing the visual language.

## New direction self-review

The first rendered pass revealed the original hero logo was receiving an explicit image height. This distorted its proportions despite using the right file. Corrected with height auto and added rendered-ratio checks. A desktop CTA wrapped unnecessarily; widened it. Small body text on the full cyan panel needed deeper ink; the dedicated on-cyan token measures 5.17:1.

Source limitations remain visible: the original logo is a 586px raster; large desktop renderings cannot acquire vector sharpness without a higher-resolution original. Generated relighting is visually matched, not mathematically guaranteed registration. These constraints are documented in the builder handoff.

Later photographic checks exposed insufficient contrast over the daylight shutter on phones. The lower local scrim was strengthened; the final sampled checks pass. The contact form now precedes addresses on phones, and the miniature alternative was reframed to keep the scene clear of the copy.

## Boundaries

No existing project photograph was creatively altered. Generated frontages/materials are explicitly concepts. Production routes, form pipeline, data, deployment and prior working-tree changes were not modified in this pass.
